# Generic native menu contract — version 1

`generic:native` exposes `native:menu` through the shared `nativeMenuPath` runtime export. Callers supply the exact semantic label path; the implementation contains no fixture- or product-specific labels. Both frontends use this same implementation through the configured caller-composed fixture. It operates on an existing borrowed Playwright browser/page and Host Runtime Adapter, with Windows UI Automation for native menu discovery and semantic actions.

The established scope is the browser-associated right-click path on headed Chrome for Windows. The caller supplies an exact page target, a stable source locator, an authorized right-click and exact menu labels. A temporary nonce binds the target to its native Chrome window and is restored on the same source document. Fresh geometry and retained DOM identity ground the target-scoped CDP right-click. This validated path does not require Windows foreground activation. Other initiation modes and other browser/platform combinations remain unestablished.

The helper discovers the real native menu through UIA, resolves exact labels, inspects ExpandCollapse state and expands only when collapsed. A separately rooted popup must be uniquely tied to the expanded parent and bound source window through UIA ancestry or a native HWND owner relationship. The helper revalidates the exact leaf and supported pattern immediately before UIA Invoke. Missing or duplicate labels, unrelated roots, stale identities, lost runtime/window/target and unsupported patterns fail closed. It does not use screen coordinates to select native menu items or invoke application handlers directly.

The result is structured evidence attached through the existing evidence recorder. UIA Invoke proves that the native pattern completed; it does not prove a browser or application outcome. A requested downstream effect requires a before/after browser observation in the same invocation lifecycle, fresh target continuity and an explicit expected outcome. A possible action followed by loss, cancellation or incomplete evidence remains uncertain and is never replayed automatically.

The established live scope is limited to the documented built-in Chrome semantic path on Chrome for Testing 154.0.8037.92. It does not establish arbitrary native desktop menus, all Chrome menu paths, other Chrome versions or other platforms. Existing format-1 schemas and the `nativeOperation` API remain compatible.
